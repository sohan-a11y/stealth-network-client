Stealth Network Client: High-performance Python HTTP client with browser TLS/JA3 fingerprint matching via curl_cffi.

---

## 🌟 Key Features

- 🥷 **Browser TLS Fingerprint Matching**: Replicates Chrome/Firefox TLS handshakes, BoringSSL ciphers, and HTTP/2 settings.
- ⚡ **High Performance**: C-extension wrapper powered by `curl_cffi` for maximum throughput.
- 🔍 **JA3 Verification Suite**: Includes built-in scripts to verify fingerprint parity against detection APIs.
- 🛡️ **Anti-Bot Bypass**: Eades Cloudflare, Akamai, and perimeter security checks effortlessly.
